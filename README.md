# Arduino Practice Sketches

This repo contains simple Arduino examples for learning and experimentation.

## Sketches

- [`blink/blink.ino`](blink/blink.ino) — the classic "Blink" sketch that toggles the built-in LED once per second.

## Getting started

1. Open the sketch in the Arduino IDE.
2. Select your board and port under **Tools**.
3. Click **Upload**.
