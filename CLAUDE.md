# Project memory

At the start of every session in this repo, read `.claude/memory/me.md` and
`.claude/memory/core.md` in full before doing anything else. If the task
relates to a specific noted project or topic, also read the matching file
under `.claude/memory/projects/` or `.claude/memory/topics/`.

When you learn something worth keeping (a preference, a decision, a fix),
append it to the matching file under `.claude/memory/topics/` or
`.claude/memory/projects/` as one `## Title [YYYY-MM-DD]` entry, and add a
one-line pointer in `core.md` when it's significant enough to surface there.
